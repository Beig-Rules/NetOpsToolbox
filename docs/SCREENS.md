# NetOps Toolbox — Screens (English, Minimal)

## Navigation (left list)
1. Dashboard
2. Devices
3. Tools
4. Firmware
5. Security
6. Playbooks
7. Reports
8. Settings

## Dashboard
- Row of black metric cards: Latency · Loss · Throughput · Alerts
- Quiet list: recent jobs, last failures
- No chart junk unless user opens details

## Devices
- Top: [Add Device]
- Filters: Site, Brand (dropdown), Model (dropdown)
- Table or sparse list: Name · IP · Brand/Model · Status · Last seen
- Detail pane: credentials state, capabilities, Backup / Open tools / Firmware

## Tools
- Actions as text list or minimal buttons: Ping · DNS · Traceroute · Port check · Subnet
- Results in monospace panel

## Firmware
- Device context (brand/model locked from registry)
- Cards: Current version · Recommended · Online catalog status
- Actions: Diagnose · Download on PC · Upgrade · Downgrade · Local file
- Job log monospace

## Security
- New hosts since baseline
- Config change alerts
- Simple severity labels

## Playbooks
- List of playbooks (name + one-line description)
- Run → preview → apply

## Reports
- Export only what matters: inventory, last audit, firmware jobs

## Settings
- Elevation status, catalog update, theme locked to Minimal B&W
